# Daily Focus

On explicit request, suggest at most three next actions from authorized current
principles, priorities and available commitments. Ask only about consequential
uncertainty. Explain evidence, tradeoffs and missing context; stale preferences
are not current commitments. Reuse [principles](templates/principles.md) and
[priorities](templates/priorities.md) only when useful in an authorized private store.

Read-only/on-demand; no scheduler, task creation or calendar changes. Verify optional
providers before use. Personal memory remains separate from bibliographic evidence.
Apply [AGENTS](../AGENTS.md) to any separately requested write.
