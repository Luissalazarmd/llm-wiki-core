# Read and connect

Copied into a host? The links below resolve from `skills/read-connect/` in the Core install that the
library rules locate ([hosts](../../docs/hosts.md)); read them there.

## When to Use

Understand, compare or navigate selected material.

## Procedure

1. Resolve the question, actual library rules and a small authorized scope.
2. Read relevant originals/locators and justified neighbors using permitted tools
   or [scoped projection](../../docs/projection-reference.md). Unknown stays unknown.
   Take initiative as the [guided loop](../../docs/knowledge-workflow.md#guided-loop) describes.
3. Before extensive proposals, give a brief sourced finding. Ask at most one
   question only if unresolved purpose, scope or criteria materially changes the
   result; otherwise proceed. Sources are never voted on; retain evidence gaps
   as open questions. Explain claims, evidence, tensions, limits and inference. Reuse explanations;
   develop useful arguments under [idea emergence](../../docs/knowledge-workflow.md#idea-emergence).
4. Answer clearly; successful reading requires no save. Send useful retention to [review/save](../review-save/SKILL.md).

For optional read-only counts over an explicitly selected Wiki scope, use
[deterministic activity and connections](../../docs/note-connections.md); only declared
note/concept roles participate. In new authorized edits, prefer its supported explicit
paths. Do not rewrite existing links or expand discovery to resolve them. Counts do
not establish importance, maturity, acceptance, MOC creation or evidence. Saving or
refreshing a report requires an actual user request and the library's writer/review
rules, with current inputs checked before saving.

## Pitfalls

Links/topic similarity do not establish scientific support. Follow [AGENTS](../../AGENTS.md).

## Verification

Check claims against originals, preserve disagreements and leave reading inputs unchanged.
