# Progressive adoption

## When to Use

Adapt a small authorized sample when requested; no migration runtime.

## Identify the starting point

Use known context: existing wiki, collected articles, authored articles, starting
from scratch, or mixtures. If unknown, ask one short question about where they are;
do not search the device. Remember: unknown is not absent; no automatic folder creation.

## Procedure

1. **Observe a sample.** Read rules, then selected external sources, personal notes,
   existing syntheses and author drafts. Use per-file custody in mixed folders.
2. Explain Raw/Review/Wiki correspondence: mapping is not acceptance. Preserve
   bytes and paths; do not move originals or rewrite foreign schema.
3. Prepare the first useful case: reuse an explanation or propose one distinct
   contribution. Obtain actual confirmation through [review/save](../review-save/SKILL.md).

## Pitfalls

Adoption permission is not note approval. Preserve authorship and unselected material.

## Verification

Read back permitted changes, account for originals and retrieve the result.
Missing writer means proposal-only; reuse can complete a case. Make no whole-library
completion claim. [AGENTS](../../AGENTS.md) owns shared boundaries.
