# Agent-guided knowledge contract

The human supplies questions, corrections and acceptance, not directory choices or engine commands. The Bibliotecario discovers this contract from AGENTS and guides a small useful next step. Read [ontology](ontology.md) only for metadata/projection work and [review contract](review-contract.md) for canonical changes. No separate workflow database or role-profile copy.

## One growing library

Raw preserves captured inputs and versions. Review owns proposals. Wiki owns accepted derived knowledge. A source does not move between stages. An article/project selects existing sources and knowledge; it does not create a parallel thematic library. Do not create a concept, map, folder, diagram or checklist just because a source was captured.

Physical organization may be flat or grouped under existing stages. Honor an existing preference; choose flat by default. Ask about grouping only if it changes the person's work. Paths are locations, not semantic identities or review states. Reorganization of already referenced files is a separate reconciled change, never a silent move. Refer to one source capture from several projects; distinct evidence versions need distinct capture IDs, not duplicated indistinguishable copies.

For an existing library, these stages map to existing responsibilities; they are not mandatory folders or a migration prerequisite. Locate the actual library and its applicable AGENTS/rules before reading content. Do not replace those instructions with Core's, move originals or assume metadata matches the strict ontology. Existing-mode discovery preserves unknown role/maturity and uses temporary path locators. Require an explicit selected file/folder scope, not a whole-library scan by default.

A map is a useful note explaining a reading path, not a compulsory category container. Retain it only when it contributes beyond its links. Temporary article links can live in an existing authoring/project note; new folder trees and copied bibliographies are unnecessary. Private authoring placement and publishing permissions remain separate choices.

## Guided loop

1. **Understand:** identify the user's current question and authorized material. Continue with sensible defaults; ask only when ambiguity affects meaning, privacy, rights, cost or scope.
2. **Capture:** resolve source identity, provenance, reuse/quotation rights and data class. Find an existing capture first. Preserve original titles and quotes. Check the actual writer capability; missing capability is a blocker to capture, not permission to invent commands.
3. **Read:** use scoped existing discovery, or strict catalog for adapted metadata, to select a focal object. Open only relevant originals and justified neighbors. A map's links are candidates, not an instruction to read the whole collection. Ordinary wikilinks do not imply agreement or source support.
4. **Connect:** state why sources or ideas relate; distinguish grouping, source support, disagreement and interpretation. Metadata validation does not establish that a claim follows from a source. Check locators independently before making a factual proposal.
5. **Discuss:** explain differences and consequences in the user's language. “Show another way” explores; “change this” requests a revision; “accept this version” can become a decision only through the verified host and exact packet binding. Clarify “that one” when ambiguous. Do not ask the human to type commands or maintain metadata.
6. **Retain:** update/reuse existing knowledge before adding a note. Prepare only useful material under the library's review policy; no duplicate queue. The original packet helper binds existing target/draft/evidence bytes, not semantic support or acceptance. Managed libraries use the writer already permitted by their own rules; verify its availability without reconstructing a Core component. Explicitly editable plain libraries can use existing host save/history tools after actual confirmation, current-version checks and recovery; the optional [plain helper](plain-saving.md) supplies only file checks. Unknown permissions mean proposal-only; independent reading continues.
7. **Resume:** retain the question, object IDs/versions, actual decisions and next step in the existing authorized continuity authority. Do not mirror the vault into memory or create a second queue.

Initiative means noticing an unclear definition, relevant connection or missing evidence inside the current task. It does not mean processing the whole backlog, changing permissions, silently changing roles or launching permanent background work.

## Navigation and understanding

Markdown remains the content surface. A small Home may link the current work and canonical stage indexes; it must not duplicate contents or introduce another lifecycle.

The original read-only projector renders a bounded navigation selection to stdout. It can provide plain wikilinks and K-Plex's existing `Children` field in a disposable view; this is view grouping, not scientific ontology or a new canonical store. No plugin is required. Do not install/reconfigure plugins without permission. Saving a view is optional and must be outside managed Raw/Review/Wiki; never feed it back as source evidence. Do not accumulate a view per article/category by default.

K-Plex navigation must be tested in the actual host before calling it integrated. K-Plex has editing actions and no verified universal readonly lock. Do not edit/rename/delete managed notes or relationships from it. Excalidraw can illustrate a question when available and authorized; drawings do not establish evidence or approval. Voice is another input channel only when the host supplies the actual selected object and verified human event; no integration is inferred from documents.

## Non-clinical worked journey

A user captures two public reports about urban tree shade. The Bibliotecario keeps each original once in Raw and asks what the user wants to understand. It reads measurement methods, suggests comparing temperature outcomes and notes differences in location and time. A shared-topic link is grouping, not proof of comparable causal effects.

If an explanation of shade measurements is worth keeping, propose one reusable concept with exact source locators/versions. A user correction requires a revised diff and new confirmation. Managed libraries stop at the proposal until the required authenticated host is connected. Plain libraries may save through their allowed host tools after real user confirmation and recovery/version checks, without claiming canonical-engine acceptance. A future article links the retained concept instead of making its own copy.

## Boundaries of this increment

Guided contract, scoped discovery, optional ontology, navigation and existing-target proposals are implemented without the private engine. AGENTS links the three portable action skills progressively; they use the existing host, not automatic native skill registration. The optional plain helper adds version/recovery checks for explicitly editable notes only. Automated capture runtime, semantic model execution inside Core, authenticated approval, state transitions, canonical apply, graphical/voice sharing and universal host interoperability are not implemented. Agent reasoning/consent come from the host, not the CLI. See [current evidence](self-contained-increment.md).
