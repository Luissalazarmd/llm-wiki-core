# Read, think, connect, retain

## Guided loop

Select the current question, relevant notes and original passages. Explain the
argument, comparable evidence, tensions and gaps. Reuse before proposing another
explanation. Retention follows [review](review-contract.md); originals stay original.

## Idea emergence

Raw originals remain unchanged. Only authored notes develop:

- **Semilla** (`seed`): bounded question, observation or hypothesis with uncertainty.
- **Síntesis** (`synthesis`): explicit organizing argument connecting ideas/evidence,
  preserving tensions and unresolved gaps.
- **Evergreen** (`evergreen`): reusable explanation with checked central claims,
  counterevidence and scope; still correctable.

This is not a source-count or link-count threshold. Trace claims to originals;
state what a proposed connection adds. Explain current/proposed maturity; new
evidence may justify reopening or correction through review. Reuse the same note
for continuous ideas. Missing maturity stays unknown. A retained seed need not
be Evergreen; publication permission is separate.
