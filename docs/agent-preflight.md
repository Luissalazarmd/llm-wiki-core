# Operational preflight

Read the [handoff](simplification-handoff.md) when resuming simplification; inspect
status, diff and untracked files before editing. Preserve local implementation.
Locate the actual library/rules and current question; establish authorized paths,
rights/privacy/provider limits and stopping condition. Observe capabilities as
available/unavailable/unverified/not required. Load one [action](../AGENTS.md).
Missing writers block dependent writes, not independent reading/proposals.
