# Operational preflight

Inspect status, diff and untracked files before editing. Preserve local implementation.
Locate the actual library/rules and current question. Infer purpose and stopping
point from the request, but use only paths, rights and providers the person or the
library rules authorize; when unclear, propose a minimal scope. Ask at most one
question, only if its answer would change the outcome. Observe capabilities as
available/unavailable/unverified/not required. Load one [action](../AGENTS.md).
Missing writers block dependent writes, not independent reading/proposals.

## Requirements

Solve these with whatever the host provides; report only what you cannot meet.

- Think: read the selected files and show the person exact text. Nothing else is needed.
- Save: only through a writer the library permits (unknown means proposal-only);
  create without overwriting, confirm the file still matches the reviewed
  version, keep the previous version outside the library, read back exact bytes.
- Optional helpers: Python 3.10+ and PyYAML. Prefer an environment outside Core
  and the library; ask once before installing anything.

Tools may vary; these outcomes and the review contract may not.
No library yet? Work in chat.
