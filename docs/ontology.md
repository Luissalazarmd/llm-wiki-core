# Three roles, connected notes

Source preserves an original; note authors an explanation, question, entity,
project or diagram; map authors a reading route. Preserve existing IDs and authorship.

## Independent dimensions

Only notes have seed/synthesis/evergreen maturity, independently of review.
Missing stays unknown. Legacy roles and developing normalize only in output;
legacy review remains unverified data. Existing relation declarations retain
source/hash/locator checks. Follow the [review contract](review-contract.md).

## One declaration, derived views

Retain declared relationships and derive inverse views.
